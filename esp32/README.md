# Порт на ESP32-S3 (Waveshare ESP32-S3-Touch-AMOLED-2.06)

Ядро общее с симулятором (`../src`). Здесь только то, что зависит от железа:

| Что | Файл | Как сделано |
|---|---|---|
| Экран и сенсор | `main/main.c` | официальный BSP Waveshare (`bsp_display_start_with_config`), LVGL 9.5.0 |
| Файлы | `main/main.c` + `src/watch/fs_posix.c` | LittleFS на разделе `storage`, смонтирован как `/flash`; тот же POSIX-код, что и на ПК |
| Сеть | `main/net_esp.c` | `esp_http_client`, HTTPS с набором корневых сертификатов |
| Wi-Fi | `main/wifi.c` | режим станции, переподключение с растущей паузой; сеть пока из menuconfig |
| Случайные числа | `main/plat_esp.c` | `esp_fill_random` |

## Сборка

Нужен ESP-IDF 5.5 (на Windows проще всего официальный установщик ESP-IDF или расширение VS Code).
Прошивать удобнее из Windows, чем из WSL: USB-порт в WSL нужно пробрасывать отдельно (usbipd).

```
cd esp32
idf.py set-target esp32s3
idf.py menuconfig          # watch-os -> Wi-Fi SSID / пароль, яркость
idf.py build
idf.py -p COM5 flash monitor
```

При первой сборке менеджер компонентов скачает BSP, LVGL 9.5.0 и LittleFS.

**Важно про прошивку.** `idf.py flash` записывает и образ файловой системы (`apps/`, `packages/`),
поэтому стирает PIN и установленные приложения. Чтобы обновить только программу: `idf.py -p COM5 app-flash`.

## Что проверено, а что нет

Проверено в песочнице с настоящим ESP-IDF 5.5 и тулчейном Xtensa:
- ядро, `launcher.c`, `wifi.c`, `net_esp.c`, `plat_esp.c` собираются и линкуются для ESP32-S3 без ошибок и предупреждений
  (проверочный проект без BSP и LittleFS: прошивка 807 КБ при разделе 4 МБ);
- `main.c` проходит проверку компилятора (`-Wall -Wextra`) по настоящим заголовкам BSP, `esp_lvgl_port` и `esp_littlefs`.

Не проверено (нужна плата):
- запуск на самих часах, экран, сенсор, скорость и расход памяти;
- скачивание зависимостей менеджером компонентов (версии `joltwallet/littlefs` и BSP) и функция образа LittleFS;
- Wi-Fi и HTTPS-запросы на реальной сети.

## Известные ограничения

- Сети с входом через страницу (captive portal, Госуслуги) не поддерживаются: часы их не пройдут.
- Сетевой запрос блокирует интерфейс до 10 секунд (выполняется в задаче LVGL; стек для неё увеличен до 16 КБ).
- Wi-Fi задаётся в menuconfig и сохраняется в прошивке; приложение «Настройки» ещё не написано.
- Нет RTC/NTP: время на экране блокировки не показывается.
- Размер flash в конфиге 16 МБ, как в примере Waveshare; на плате по описанию 32 МБ, можно увеличить.
- Картинки/микрофон/динамик/датчики/батарея не используются.
