# Формат приложений (JSON)

Приложение - папка в `apps/<id>/` с двумя файлами. Приложение ничего не исполняет само: оно описывает экраны
и просит ядро о действиях (системные вызовы). Идентификатор `<id>` - имя папки (буквы, цифры, `_`, `-`).

## manifest.json

```json
{"name":"Tools","icon":"list","color":"#06B6D4","permissions":["net","storage"]}
```
- `name` - до 47 байт (русская буква = 2 байта); более длинное обрезается по границе символа.
- `icon` - один из ключей: `calc list edit bell gps settings mail audio image call plus ok home file folder video wifi battery charge refresh play trash download`.
- `color` - цвет плитки `#RRGGBB`.
- `permissions` - `net` (запросы в интернет и к ИИ), `storage` (постоянное хранилище). Без разрешения вызов не выполняется.

## app.json

```json
{
  "start": "main",
  "vars": { "name": "" },
  "screens": { "main": { "title": "Hello", "ui": [ ...виджеты... ] } }
}
```
`vars` - начальные переменные. Переменные - текст (до 127 байт, имя до 23 символов `A-Za-z0-9_`). В любом тексте виджета
`@имя` подставляет значение переменной, `@@` даёт символ `@`. Подписи с `@` обновляются сами при изменении переменной.
Верхнюю панель с заголовком и кнопкой «назад» рисует ядро. Лимиты: 4 уровня вложенности, 64 виджета на экран, 48 подписанных на переменные подписей и индикаторов на экран.

## Виджеты

| type | поля | что делает |
|---|---|---|
| `label` | `text`, `color`, `size` (`small`/`large`) | текст |
| `button` | `text`, `color`, `on_click` | кнопка; `on_click` - список действий |
| `input` | `var`, `placeholder` | поле ввода, значение пишется в переменную |
| `switch` | `text`, `var` | переключатель, в переменную пишет `0` или `1` |
| `list` | `items`, `var` (по умолчанию `item`), `on_click` | пункты-кнопки (до 12); по нажатию текст пункта попадает в переменную и выполняются действия |
| `table` | `src` или `rows`, `header` | таблица до 4 колонок и 16 строк; `src` - имя таблицы от `ai.ask_table`, `rows` - готовые строки `[["a","b"],[1,2]]`; `header: true` закрашивает первую строку |
| `slider` | `var`, `min`, `max`, `text` | ползунок, значение в переменную (целое) |
| `bar` | `var`, `min`, `max`, `color` | индикатор, следует за значением переменной |
| `spacer` | `h` | отступ |
| `row` / `col` | `children` | контейнер горизонтальный или вертикальный |

Неизвестные типы и поля пропускаются без ошибки. Картинок (`image`) пока нет: нужен декодер и файловый драйвер LVGL.

## Действия (системные вызовы)

Список действий `[{"do": "имя", ...}, ...]`, до 16 штук; после `goto`, `back` и `confirm` остальные не выполняются.
В значениях можно использовать `@переменные`.

| do | поля | разрешение | что делает |
|---|---|---|---|
| `set` | `var`, `value` | | записать значение |
| `add` | `var`, `value` | | прибавить число (по умолчанию 1) |
| `goto` | `screen` | | перейти на экран |
| `back` | | | назад |
| `toast` | `text` | | всплывающее сообщение |
| `confirm` | `title`, `text`, `on_yes` | | окно подтверждения от ядра; `on_yes` - действия при «Да» |
| `ai.ask` | `q`, `out` | `net` | короткий ответ ИИ в переменную `out` (сейчас заглушка) |
| `ai.ask_table` | `q`, `out` | `net` | ответ в виде таблицы с именем `out` (сейчас заглушка) |
| `store.set` | `key`, `value` | `storage` | сохранить (до 255 байт; до 32 ключей на приложение) |
| `store.get` | `key`, `out`, `default` | `storage` | прочитать в переменную `out` (по умолчанию `key`); нет ключа - значение `default` |
| `store.remove` | `key` | `storage` | удалить ключ |

Хранилище у каждого приложения своё: данные лежат в `data/apps/<id>.json`, приложения не видят чужие данные и пути к файлам.

## Примеры

Рабочие образцы: `apps/ask` (ввод и вызов ИИ), `tests/apps/tools` (ползунок, индикатор, список, таблицы, хранилище)
и `tests/apps/hello` (ввод и переход между экранами). Образцы из `tests/` в прошивку не попадают, их читает `tests/smoke.c`.
Автоматическая проверка всех приложений: `cmake --build build --target watch_smoke && ./bin/watch_smoke`.
