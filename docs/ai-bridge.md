# Мост ИИ: часы -> телефон -> провайдер ИИ (по умолчанию OpenRouter)

Зачем: API ИИ из России недоступны без VPN, а раздача Wi-Fi с телефона идёт мимо VPN. Поэтому часы не ходят в интернет
сами: они спрашивают телефон. Приложение **Watch AI** (`android-ai/`) идёт в OpenRouter под VPN, но принимать часы напрямую оно
не может: ответ приложения под VPN уходит в туннель, а не в раздачу, и часы не могут подключиться. Поэтому часы говорят с
основным приложением **Watch Sync** (`android/`, без VPN), а оно передаёт запрос в Watch AI по loopback.
Ключ API хранится только в Watch AI, на часах его нет.

## Схема

```
часы --HTTP POST /ask {"q":"..."}--> Watch Sync (шлюз раздачи, порт 8787, вне VPN)
                                      --TCP, 127.0.0.1:8788--> Watch AI (под VPN) --HTTPS--> openrouter.ai
часы <---------------------- текст ответа (UTF-8) <----------------------------------------------
```

- Адрес телефона часы берут сами: это шлюз их Wi-Fi (`net_phone_host()`).
- Watch Sync (`AiRelayService`, `Relay.kt`) ничего не разбирает: байты идут как есть. Если Watch AI не запущен, часы получат 502 с текстом.
- Watch AI слушает только `127.0.0.1:8788`.
- Ответ 200: тело = текст. Любой другой статус: тело = текст ошибки (часы покажут его тостом).
- `GET /ping` отвечает `ok` (проверка связи).
- Ответ ограничен переменной приложения (`VAR_VAL` = 128 байт), длиннее обрезается с многоточием.

## Настройка

1. Установить APK `watch-ai-debug.apk`, кнопкой **Provider** выбрать провайдера (OpenRouter, OpenAI, Groq, Google Gemini, DeepSeek), ввести его ключ и нажать **Save and start**.
   Ключ и модель хранятся отдельно для каждого провайдера: при смене провайдера ключ прежнего не стирается и вернётся, когда выберешь его снова.
   Старый одиночный ключ при обновлении автоматически становится ключом OpenRouter.
   Дальше описан OpenRouter; у остальных провайдеров список моделей приходит из `GET /models` с ключом, без цен и без пометки free. Модель выбирается кнопкой **Choose model**:
   список приходит из OpenRouter (`GET /api/v1/models`), по умолчанию показаны только бесплатные (`:free`), есть поиск.
   По умолчанию стоит `openai/gpt-4o-mini` (платная). Сверху списка закреплён `openrouter/free`: роутер сам берёт любую
   свободную бесплатную модель, и если одна занята, пробует другую (платной он не подставит). Лимит бесплатных моделей:
   20 запросов в минуту и 50 в день на весь аккаунт OpenRouter (1000 в день, если когда-либо пополнено от $10); при превышении часы покажут ошибку 429.
2. Установить Watch Sync и открыть его (сервис моста запускается сам), включить VPN **только** для Watch AI, не для Watch Sync, включить раздачу Wi-Fi, подключить часы к раздаче.
3. Отключить экономию батареи для обоих приложений, иначе Android может усыпить сервис при погашенном экране.

## Безопасность

Токена нет: запрос принимается от любого устройства в вашей раздаче. Раздача защищена паролем WPA, так что тратить
ключ могут только подключённые к ней устройства. Сервис слушает все интерфейсы телефона, держите раздачу под паролем.

## В приложениях на часах

Системный вызов `ai.ask` (`{"op": "ai.ask", "q": "...", "out": "answer"}`) блокирует интерфейс до ответа (до 60 с)
и кладёт ответ или `Error: ...` в переменную. `ai.ask_table` (`{"do": "ai.ask_table", "q": "...", "out": "имя"}`) просит таблицу: телефон отвечает JSON
`{"rows": [[...], ...]}` (первая строка - заголовок, до 16 строк и 4 столбцов; markdown-таблицу тоже разбирает),
ядро кладёт её под именем `out`, показывается виджетом `{"type": "table", "src": "имя", "header": true}`.

## Фото

Запрос `POST /ask {"q": "...", "img": "<JPEG в base64>"}` (до ~1.5 МБ). Телефон шлёт картинку в OpenRouter (`image_url`),
нужна модель с поддержкой изображений (`openai/gpt-4o-mini` умеет). Ответ - простой текст до 900 байт.
На часах: Gallery -> просмотр фото -> кнопка AI.
