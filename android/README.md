# Watch Sync (Android)

Приложение отправляет на часы фото и время по Wi-Fi. Протокол: `../docs/sync-protocol.md`.

## Как получить APK

Сборка идёт в GitHub Actions, ничего ставить на телефон или ПК не нужно:

1. Отправьте репозиторий на GitHub (`git push`). Workflow `.github/workflows/android.yml` запустится сам при изменениях в `android/`.
   Можно запустить и вручную: вкладка **Actions**, **Android APK**, **Run workflow**.
2. Когда сборка зелёная, откройте её и скачайте артефакт **watch-sync-debug-apk** (внутри `app-debug.apk`).
3. Разрешите установку из неизвестных источников и установите APK.

Локально (нужны JDK 17, Android SDK и Gradle 8.9): `cd android && gradle assembleDebug`.

## Как пользоваться

1. На часах откройте плитку **Sync**: на экране адрес и 6-значный код.
2. В приложении введите адрес (например `192.168.0.5`) и код, нажмите **Choose photos and send**, выберите фото.
3. Приложение уменьшает фото до 410x502, делает миниатюру 120x120, учитывает поворот из EXIF и отправляет.
   Уже переданные фото пропускаются. Время часов выставляется при каждом подключении.

Телефон и часы должны быть в одной Wi-Fi сети. Для симулятора в Termux на том же телефоне введите адрес `127.0.0.1`.

## Прошивка полным образом по USB (с сохранением данных)

Кнопка **Flash full image over USB** прошивает `watch-os-full.bin` прямо с телефона: часы подключаются к телефону кабелем USB-C OTG.
Галочка **Keep my data** (включена по умолчанию) пропускает разделы `nvs` и `storage`: PIN, приложения, фото, музыка и Wi-Fi остаются.
Без галочки часы стираются целиком. Каждая записанная область проверяется по MD5.
Если часы не находятся или не отвечают, зажмите кнопку BOOT и воткните кабель, затем повторите.
Протокол и логика проверяются на JVM против поддельного ROM-загрузчика: `python3 tests/run_flash_selftest.py <kotlinc>`.
Не проверено на живых часах и телефоне.

## Что внутри

- `WatchClient.kt` - клиент протокола на чистом Kotlin; проверяется на JVM: `python3 tests/run_kotlin_selftest.py <sync_server> <kotlinc>`;
- `PhotoPrep.kt` - подготовка фото (Bitmap, EXIF, JPEG baseline с JFIF);
- `MainActivity.kt` - экран без внешних библиотек.

Не проверено: сборка Gradle и работа приложения на телефоне (в среде разработки не было Android SDK).
